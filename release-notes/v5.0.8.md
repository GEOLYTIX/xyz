## What's Changed

### Filter and Dropdown Fixes

- **Removed dropdown pills are no longer sent with the next selection.**
  In a filter with `dropdown_pills: true`, selecting A, removing its pill and then selecting B applied the filter as `[A, B]` although only the B pill was shown. Removing a pill now deletes the entry from the selection, so the filter is `[B]`, and each selection applies the filter once instead of twice. The location count in the filter panel also no longer lags one change behind on slow layer requests: it waits for the layer to load, shows `?` while an update is pending, and discards counts from earlier filter or viewport changes. Thanks @dbauszus-glx! [#3012](https://github.com/GEOLYTIX/xyz/pull/3012)

- **Dropdown search now selects an option typed out in full.**
  With `dropdown_search: true`, typing an option's complete value and then picking it from the list, or pressing Enter, did nothing because the input value did not change. Picking the option, pressing Enter or leaving the field after typing an exact title now selects it. Duplicate titles no longer toggle more than one entry. Thanks @dbauszus-glx! [#3006](https://github.com/GEOLYTIX/xyz/pull/3006)

### Layer, Theme and Dataview Fixes

- **A layer hidden while out of zoom range stays hidden when zooming back in.**
  Hiding an out-of-range layer through a `key` location entry, `layer.remove()` or a plugin left it in the `layers` URL hook, so it was shown again on the next pan or zoom within range. Only the automatic zoom-range hide now keeps the layer for redisplay. A layer hidden any other way is removed from the hook and its toggle is turned off. Thanks @dbauszus-glx! [#3011](https://github.com/GEOLYTIX/xyz/pull/3011)

- **Graduated themes pick the correct category in every browser.**
  The category sort comparator never returned a positive value, so the sort order depended on the browser engine. In Firefox, `greater_than` themes gave every feature the first category's style. Categories are now sorted consistently, and each feature gets the category that matches its value: for `greater_than`, the highest category value at or below the field value; for `less_than`, the lowest at or above it. Values outside the range take the nearest category. Thanks @AlexanderGeere! [#3003](https://github.com/GEOLYTIX/xyz/pull/3003)

- **Dataviews reappear when their layer is toggled off and on.**
  When a layer and its dataview both had `display: true`, turning the layer off and on left the dataview hidden and its checkbox unticked, both in the layer panel and in a `target: "tabview"` tab. The dataview now comes back with the layer. A dataview the user turned off still stays off. Thanks @simon-leech! [#3000](https://github.com/GEOLYTIX/xyz/pull/3000)

### Interface Fixes

- **Dialogs keep their position when reopened after the map is resized.**
  A dialog's `ResizeObserver` stayed connected after the dialog closed. Resizing the target then reset the closed dialog's position, so it reopened in the wrong place, and repositioning inside the observer callback could raise "ResizeObserver loop" errors. The observer now disconnects on close, reconnects when the dialog is shown, and repositions on the next animation frame. Thanks @dbauszus-glx! [#3001](https://github.com/GEOLYTIX/xyz/pull/3001)

- **Numeric inputs no longer spill out of expanded infoj groups.**
  Numeric inputs in an expanded infoj group ran 1em past the right edge of the group. Every child of a group is now limited to the width of its column. Thanks @simon-leech! [#2998](https://github.com/GEOLYTIX/xyz/pull/2998)

- **The consent dialog shows a translated title.**
  The consent plugin's dialog showed the raw string `mapp.user.consent` as its header. It now uses the new `consent_title` dictionary entry, which is translated in all bundled languages. A `title` set in the plugin config still takes precedence. Thanks @dbauszus-glx! [#3018](https://github.com/GEOLYTIX/xyz/pull/3018)

### Login and Email

- **A failed browser login shows the login form with a readable message.**
  A failed login showed a blank page with a raw message key such as `auth_failed` unless the redirect cookie was still present, for example when logging in at the instance root or after the cookie had expired. Browser requests now get the login view with the translated message. API clients still get a plain-text `401`. Email templates also changed: `text` and `html` values without a provider prefix are now sent as inline bodies, and an email whose template source fails to load is logged and not sent, instead of being sent with the error as its body. Thanks @simon-leech! [#2999](https://github.com/GEOLYTIX/xyz/pull/2999)

### MAPP Library

- **The MAPP library now runs without MAPP UI.**
  The `mapp` library no longer depends on `mapp.ui`. Plugins that add buttons now live in the UI library and are still registered on `mapp.plugins` when the UI loads, so locale configs need no changes. The context menu for drawing and modifying moved into the mapview, and `mapp.css` no longer loads fonts, colours or body styles. `mapview.renderComplete` now waits until vector data has loaded, superseded vector responses are discarded, and `mapp.utils.xhr` rejects on network errors instead of never settling. The Update Layer button in the JSON editor, which threw on every call, works again. `layer.update()` and `mapp.ui.elements.contextMenu` were removed. A new `pnpm testview` package serves themed test mapviews from the in-memory development database. Thanks @dbauszus-glx! [#2988](https://github.com/GEOLYTIX/xyz/pull/2988)

### Build, Release and CI

- **Release builds are now committed to `main`, and `patch` is synced after each release.**
  The release workflow committed the MAPP bundles to the release tag only, which left `main` without them. The build commit is now pushed to `main` together with the tag, missing bundles on `main` are rebuilt, and `main` is merged back into `patch` after the GitHub release is created. `RELEASING.md` describes the manual sync for when that merge conflicts. Thanks @dbauszus-glx! [#2994](https://github.com/GEOLYTIX/xyz/pull/2994)

- **GitHub Actions now run on Node 24 releases.**
  The checkout, setup-node, pnpm, SonarQube and Pages actions were updated away from deprecated Node 20 releases, and each pinned SHA is now labelled with its version. Workflows run on `ubuntu-26.04`, and Dependabot now opens one grouped update for GitHub Actions each month against `patch`. Thanks @dbauszus-glx! [#2993](https://github.com/GEOLYTIX/xyz/pull/2993)

- **SonarQube is skipped for Dependabot pull requests.**
  Dependabot pull requests cannot read `SONAR_TOKEN`, so their SonarQube job failed. The scan is now skipped for Dependabot and fork pull requests. Thanks @dbauszus-glx! [#2997](https://github.com/GEOLYTIX/xyz/pull/2997)
