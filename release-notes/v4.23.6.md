## What's Changed

### Cloudinary Upload Fixes

- **Prevented failed Cloudinary uploads from leaving location views disabled.**
  Image and document uploads that returned a non-success HTTP status could continue processing and leave the location view stuck. Failed uploads now display an alert, stop before updating the location, and re-enable the view. Thanks @dbauszus-glx! [#2908](https://github.com/GEOLYTIX/xyz/pull/2908)

### Filter Fixes

- **Fixed `include` filtering for multi-filter configurations.**
  Entry filters could appear even when their fields were not listed in `filter.include`, because multi-filter configurations always enabled `includeAll`. Explicit inclusion lists are now respected, while `includeAll` remains enabled when no list is provided. Thanks @AlexanderGeere! [#2910](https://github.com/GEOLYTIX/xyz/pull/2910)

### Deployment Fixes

- **Restored lockfiles to Vercel deployments.**
  Excluding `package-lock.json` and `pnpm-lock.yaml` through `.vercelignore` caused deployments such as `v4.23.5` to fail. Vercel can now include the repository lockfiles and install dependencies correctly. Thanks @AlexanderGeere! [#2907](https://github.com/GEOLYTIX/xyz/pull/2907)

### Testing and Documentation

- **Improved shared Vitest scaffolding for console output.**
  Tests previously repeated their own setup for capturing or suppressing console messages. The new `mockConsole` helper centralizes that behavior, restores console methods after testing, and is documented for future test development. Thanks @RobAndrewHurst! [#2905](https://github.com/GEOLYTIX/xyz/pull/2905)
