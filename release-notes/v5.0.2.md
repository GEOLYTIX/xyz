## What's Changed

### User Registration Fixes

- **Fixed email verification links and plain-text messages in the user registration flow.**
  Two bugs broke new user registration and password reset in v5.0.1. First, the router registered the public `/api/user/verify` route without a `key` segment, so the tokened link in the verification email fell through to the authenticated `/api/user` route and redirected the visitor to the login screen. The route is now `/api/user/verify{/:key}`. Second, `languageTemplates` passed every resolved template through `getSrc`, which rejects a string without a provider prefix such as `file:` or `https:`. A plain localised message such as `User not verified or approved` errored and the template key was returned instead. Only strings with a provider prefix are now resolved through `getSrc`. New tests cover the verify route and both template cases. Thanks @AlexanderGeere! [#2944](https://github.com/GEOLYTIX/xyz/pull/2944)

### Filter and MVT Layer Fixes

- **Fixed MVT `wkt_properties` layers showing stale or blank features after a filter change.**
  Reloading an `mvt` layer with `wkt_properties: true` cleared and refreshed the vector tile sources on every filter, style, or params change, leaving the map empty until the properties query returned. A filter query with no result also left every feature on the map because a null response ended the reload early. The reload now returns early for `wkt_properties` layers and repopulates `featuresObject` from the `wkt` query. Features not in the response stop rendering through `featureStyle`. The tile sources are only refreshed when the response contains a feature ID not previously rendered, such as a newly created location. Non-`wkt_properties` MVT layers keep the previous clear and refresh behaviour. The filter panel also gains a `filter: false` opt-out on infoj entries, derives the filter type from `entry.type` when none is configured, and disables the filter drawer while the layer is hidden with the new `disableOnHide` default. A `filter_numeric` slider at the data's own min and max no longer triggers a reload, `deleteFilter` skips the reload when the field is not in `layer.filter.current`, and the `filter_in` distinct values query falls back to the first table in `layer.tables` when the layer is out of zoom range. The `locationCount` query now sends `geom`, and `layerQuery` responds with a `400` when `viewport` is requested without `geom` and `srid`. Thanks @dbauszus-glx! [#2938](https://github.com/GEOLYTIX/xyz/pull/2938)
