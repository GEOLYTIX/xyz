## What's Changed

### Map and Interaction Fixes

- **Fixed legends not rendering after a theme change or for layers displayed by default.**
  Legend rendering ran only from `layer.showCallbacks`, a queue that fires from `layer.show()`. Switching a layer's theme goes through `reload()` instead, and a layer displayed by default already runs its `show()` callbacks before the style panel exists, so in both cases the legend stayed blank. `theme(layer)` now renders the legend immediately when the layer is already displayed, and the theme-swap handler renders the new legend directly before calling `reload()`. Thanks @simon-leech! [#2945](https://github.com/GEOLYTIX/xyz/pull/2945)

- **Fixed a stray Escape-key listener left behind after modifying a geometry.**
  An earlier change moved `finish()` out of the `modify()` closure, so its `keyup` removal no longer matched the `escape` handler that `modify()` had added, and `removeEventListener` silently no-oped. Every modify session leaked its listener, and a later Escape press replayed all the stale handlers, finishing whatever interaction was currently active instead of just the modify session. The handler is now stored on the interaction instance and removed by that same reference, so `finish()` always clears the listener it added. Thanks @simon-leech! [#2946](https://github.com/GEOLYTIX/xyz/pull/2946)
