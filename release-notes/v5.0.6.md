## What's Changed

### Login and Deployment

- **`SECRET_KEY` now accepts an inline PEM private key.**
  Previously `SECRET_KEY` was always treated as a file path, so deployments had to write the RS256 private key to a `*.pem` file and ship it in the bundle. Deployments that keep the key in a secret manager could not pass it directly as an environment variable.

  When the value of `SECRET_KEY` starts with `-----BEGIN` (leading whitespace is ignored), it is now used as the PEM key directly. Any other value is still read as a file path relative to `XYZ_CWD` or the workspace root, so existing setups are unchanged. An inline key does not need a `*.pem` entry in the Vercel `includeFiles` config. The `login-public-key` script now derives the public key from the same resolved secret, so it works with both forms. `DEPLOYMENT.md` and `SETUP.md` document both options. Thanks @RobAndrewHurst! [#2968](https://github.com/GEOLYTIX/xyz/pull/2968)

### Location Entry Fixes

- **Cloudinary uploads are now available on mobile.**
  The upload zone for cloudinary image and document entries had the `mobile-display-none` class, so users on small screens could not upload files from an editable location. The class has been removed, and phone users can now upload images and documents, including photos taken with the camera. Thanks @dbauszus-glx! [#2962](https://github.com/GEOLYTIX/xyz/pull/2962)

### Maintenance

- **Added a `review-pr` Claude skill.**
  The new skill reviews a pull request, branch, or uncommitted changes in XYZ/MAPP and reports to the terminal. It reads each touched method in full and checks listener and callback registration, changes that spread across too many modules, test coverage for touched modules, and JSDoc conformance with `DOCUMENTATION.md`. Thanks @anush-933! [#2959](https://github.com/GEOLYTIX/xyz/pull/2959)
