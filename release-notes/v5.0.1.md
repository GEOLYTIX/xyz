## What's Changed

### Roles and Workspace Fixes

- **Prevented layers and locales with only object-valued roles from leaking to unauthorised users.**
  A layer or locale whose `roles` object contained only object-valued keys, such as role-specific property merges, collected no access gate and was granted to every user regardless of their roles. The layer or locale itself is now gated by every one of its role keys, while nested objects continue to merge role-specific properties without hiding entries from users lacking the role. Thanks @simon-leech! [#2941](https://github.com/GEOLYTIX/xyz/pull/2941)

- **Improved the response time of the workspace `scopes` endpoint.**
  Every request to `/api/workspace/scopes` previously forced a full workspace cache rebuild, refetching every source and recomposing every locale and layer, and disrupting concurrent requests sharing the cache. Scopes are now resolved from the cached workspace, concurrent callers share a single composition, and a rebuild only occurs when the cached workspace has expired or the `force=true` parameter is provided. The Account Administration user list no longer blocks on this request and populates roles asynchronously. Thanks @RobAndrewHurst! [#2940](https://github.com/GEOLYTIX/xyz/pull/2940)

### Map Interface Fixes

- **Themed legends are now generated when a layer is shown.**
  Legends for themed layer styles were built as soon as the layer style panel was created, even for layers not displayed on the map. The legend content is now generated from a `showCallback` method when the layer is displayed, and refreshes each time the layer is shown. Thanks @dbauszus-glx! [#2924](https://github.com/GEOLYTIX/xyz/pull/2924)

- **Fixed dataviews rendering in the wrong location after restoring a saved view.**
  A dataview's `target` string is replaced with the rendered HTML element at runtime, and the `jsonParser` strips that element when a view is saved. Restoring the saved view then rendered the dataview inline in the layer panel instead of its configured `tabview`. The configured target is now stored as `_target` and reinstated when the `target` is missing. Thanks @simon-leech! [#2942](https://github.com/GEOLYTIX/xyz/pull/2942)

- **Restored the Back option in the nested locale dropdown.**
  The entry to step back up a level from a nested locale rendered as a blank, unlabelled row since the recursive template changes in [#2883](https://github.com/GEOLYTIX/xyz/pull/2883). The entry is now labelled with the new `locale_back_option` dictionary term, `<- Back`. Thanks @AlexanderGeere! [#2939](https://github.com/GEOLYTIX/xyz/pull/2939)
