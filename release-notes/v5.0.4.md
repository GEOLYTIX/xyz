## What's changed

### Locale and workspace fixes

- **Fixed base-layer order and prevented admin workspace requests from corrupting cached settings.**
  Locales using a `template` could list local layers before base layers, and base defaults could overwrite template settings. Base layers now stay first. Settings apply in order of base defaults, locale template, then explicit locale settings, with later values taking precedence. Locales without their own template still inherit the base template.

  Admin workspace `test` and `compose` requests could also overwrite cached role rules, leaving later users with settings their roles should exclude. Both endpoints now build their output separately from the cache. This also stops `compose` from deleting cached `templates` and `scopes`, which could cause later requests to fail. Thanks @RobAndrewHurst! [#2953](https://github.com/GEOLYTIX/xyz/pull/2953)

### Documentation

- **Added a step-by-step guide to publishing XYZ releases.**
  `RELEASING.md` explains how to bump the version, write release notes, run checks, and publish a tag. It covers release verification and failed workflows, and makes clear that a release tag does not deploy the app or publish an npm package. Both `README.md` and `DEVELOPING.md` link to the guide. Thanks @RobAndrewHurst! [#2949](https://github.com/GEOLYTIX/xyz/pull/2949)
