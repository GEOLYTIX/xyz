# Plugins

Plugins add tools, layer formats, theme, entry and filter types, or replace
MAPP methods, without changing the MAPP and MAPP.UI libraries. A workspace
turns them on with locale and layer keys; see
[locale plugins](../workspace/locale/plugins.md) for the configuration.

- [Authoring](authoring.md) - What plugins are, how the mapview loads and runs them, how to author and version one, and the xyz_plugins repository; use when adding a plugin.
- [Extension points](extension-points.md) - The registries plugins add layer formats, theme, entry, filter and icon types to, and how to replace or wrap a MAPP method; use when a plugin adds a type or changes core behaviour.
